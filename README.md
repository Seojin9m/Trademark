# Trademark

A quantitative trading system for personal tech-stock portfolio management. Trademark ingests market data, computes factor-based signals, generates trade proposals, and runs them through an LLM judge — all with a React dashboard for monitoring and control.

## Stack

- **Backend:** Python, FastAPI, DuckDB, Polygon.io
- **Frontend:** React, TypeScript, Vite
- **AI:** LLM-powered trade judge, news research agent, and chat assistant
